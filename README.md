# Real-Time Emotion Detection using CNN

A real-time facial emotion detection project built using **Python, TensorFlow/Keras, OpenCV, and CNN (Convolutional Neural Network)**.

The system detects a face through the webcam and predicts the person's facial emotion in real time.

## 😊 Emotions Detected

The model can classify the following 7 emotions:

- Angry
- Disgust
- Fear
- Happy
- Sad
- Surprise
- Neutral

## 🚀 Features

- Real-time emotion detection using webcam
- Face detection using OpenCV Haar Cascade
- CNN-based emotion classification
- Grayscale 48x48 input images
- Supports 7 different emotions
- Displays the detected emotion directly on the webcam window

## 🛠️ Technologies Used

- Python
- TensorFlow
- Keras
- OpenCV
- NumPy
- CNN
- Haar Cascade
